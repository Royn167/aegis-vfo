# Aegis VFO - Virtual Family Office Management System

A comprehensive family office management platform built for efficiency, security, and scalability.

## Features

- 👥 **Principal Management**: Family members, advisors, trustees
- 💰 **Asset Tracking**: Real estate, investments, collectibles
- 🏢 **Entity Management**: Trusts, LLCs, foundations
- 🔗 **Relationship Mapping**: Complex ownership and beneficiary structures
- 📊 **Financial Analytics**: Net worth, asset allocation, performance
- 🔒 **Enterprise Security**: Field-level encryption, audit trails, MFA
- 📱 **Modern UI**: Responsive design with interactive visualizations

## Quick Start

### Development Setup
```bash
# Clone the repository
git clone https://github.com/yourusername/aegis-vfo.git
cd aegis-vfo

# Copy environment file
cp .env.example .env

# Start with Docker
docker-compose up -d

# Create admin user
npm run create-admin

# Access the application
open http://localhost:3000
